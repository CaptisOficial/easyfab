# EasyFAB

Aplicación de escritorio para capturar y consolidar el trabajo de ingeniería de Fabrication (10.FAB), Kawasaki Motores de México. Tauri v2, Rust, React 19 y TypeScript; datos locales en la carpeta corporativa configurada.

Consulta [el índice del proyecto](docs/indice.md) para conocer el sistema, el plan, los módulos, la arquitectura y cómo contribuir.
